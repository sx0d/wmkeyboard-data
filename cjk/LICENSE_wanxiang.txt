pinyin_v2.tsv, the two-word and one-word keys kept, their values rescaled onto
the counts of pinyin_ngrams.tsv, and merged with that file
(tools/build_pinyin_ngrams_v2.py). The .gram file format was read with
reference to librime-octagram (BSD-3-Clause, https://github.com/lotem/librime-octagram)
and darts-clone (BSD-2-Clause, https://github.com/s-yata/darts-clone); no code
